# Поиск и фильтрация шаблонов

## 📋 Описание

Добавлена удобная система поиска, сортировки и фильтрации шаблонов, позволяющая быстро находить нужные шаблоны среди 76+ готовых решений.

## 🎯 Возможности

### 🔍 Поиск
- **Полнотекстовый поиск** по названию, описанию и категории шаблона
- **Мгновенная фильтрация** результатов при вводе
- **Кнопка очистки** поиска (✕)
- **Регистронезависимый** поиск

### 📊 Сортировка
Доступны 5 вариантов сортировки:
1. **По имени (А-Я)** - алфавитный порядок по возрастанию
2. **По имени (Я-А)** - алфавитный порядок по убыванию
3. **По кол-ву секций ↑** - от простых к сложным
4. **По кол-ву секций ↓** - от сложных к простым
5. **По категории** - группировка по типу сайта

### 🎛️ Фильтры
- **Фильтр по категориям** - 11 категорий (Маркетплейс, Портфолио, Ресторан, Фитнес, Агентство, E-commerce, Блог, Образование, Медицина, Недвижимость, Путешествия)
- **Расширяемая панель фильтров** - кнопка "Фильтры" показывает/скрывает дополнительные настройки
- **Статистика фильтрации** - показывает количество найденных шаблонов и процент совпадений
- **Кнопка сброса** - быстрый сброс всех фильтров и поиска

### 📈 Статистика
В панели фильтров отображается:
- **Всего шаблонов** - общее количество доступных шаблонов
- **Категорий** - количество доступных категорий
- **Найдено** - количество шаблонов, соответствующих фильтрам
- **Совпадений** - процент найденных шаблонов от общего количества

## 🎨 Интерфейс

### Поисковая строка
- Расположена в верхней части секции шаблонов
- Иконка 🔍 слева для визуального обозначения
- Placeholder: "Поиск по названию или описанию шаблона..."
- Автоматическая фильтрация при вводе

### Панель фильтров
- Кнопка "🎛️ Фильтры" для показа/скрытия расширенных настроек
- Счётчик "Показано X из Y шаблонов"
- Выпадающий список сортировки справа

### Расширенные фильтры (при нажатии на "Фильтры")
- **Категории** - кнопки для быстрого выбора категории
- **Статистика** - 4 карточки с ключевыми метриками
- **Сброс фильтров** - кнопка появляется только если активны фильтры

### Пустые результаты
Если по запросу ничего не найдено:
- Иконка 🔍
- Сообщение "Ничего не найдено"
- Подсказка изменить запрос
- Кнопка "Сбросить фильтры"

### Логика фильтрации
Используется `useMemo` для оптимизации производительности:
1. Фильтрация по категории
2. Фильтрация по поисковому запросу (название, описание, категория)
3. Сортировка результатов

### Производительность
- **useMemo** - мемоизация отфильтрованных результатов
- **Мгновенная фильтрация** - без задержек при вводе
- **Оптимизированный рендеринг** - пересчёт только при изменении зависимостей

## 🚀 Использование

### Базовый поиск
1. Введите текст в поисковую строку
2. Результаты фильтруются автоматически
3. Нажмите ✕ для очистки поиска

### Фильтрация по категории
1. Нажмите "🎛️ Фильтры"
2. Выберите нужную категорию
3. Отобразятся только шаблоны выбранной категории

### Сортировка
1. Выберите вариант сортировки из выпадающего списка
2. Результаты автоматически пересортируются

### Комбинированная фильтрация
Можно комбинировать поиск, фильтры и сортировку:
1. Введите поисковый запрос
2. Выберите категорию
3. Выберите способ сортировки
4. Система применит все фильтры одновременно
