1. **Выбор платформы публикации:**
   - 📱 Telegram
   - 🔵 ВКонтакте
   - 📷 Instagram
   - 📺 YouTube
   - 🎵 TikTok
   - 📝 Блог

2. **Типы контента:**
   - 📄 Статьи
   - 🎬 Видео
   - 🖼️ Изображения
   - 🎵 Аудио
   - 💬 Посты

3. **Расписание публикации:**
   - Каждый час
   - Ежедневно
   - Еженедельно
   - Ежемесячно
   - По пользовательскому расписанию

4. **Настройка времени:**
   - Выбор времени публикации
   - Выбор дней недели
   - Автоматическая публикация

#### Пример использования:
```tsx

  onScheduleCreate={(schedule) => {
    console.log('Создано расписание:', schedule);
  }}
/>
```

## ⚙️ Управление ценами в админ-панели

### Компонент: `PricingManagement`

#### Функции:
1. **Управление тарифами подписок:**
   - Добавление/удаление тарифов
   - Изменение цен
   - Редактирование списка функций
   - Выделение популярных тарифов

2. **Управление ценами шаблонов:**
   - Установка цены за разовую покупку
   - Установка цены за подписку
   - Массовое редактирование

3. **Настройка способов оплаты:**
   - Включение/отключение платежных систем
   - Настройка комиссий
   - Мониторинг транзакций

#### Интерфейс:
```tsx
<PricingManagement />
```

### Доступ в админ-панели:
1. Откройте админ-панель (кнопка "⚙️ Панель управления")
2. Перейдите на вкладку "💰 Цены"
3. Управляйте тарифами и ценами шаблонов

## 🚀 Быстрый старт

### 1. Создание расписания публикаций:
```tsx
import { PublicationScheduler } from './components/PublicationScheduler';

function MyBlog() {
  const handleScheduleCreate = (schedule) => {
    console.log('Новое расписание:', schedule);
    // Сохранение в базу данных
  };

  return (
    <PublicationScheduler 
      templateId="my-blog-123"
      onScheduleCreate={handleScheduleCreate}
    />
  );
}
```

### 2. Настройка оплаты:
```tsx
import { PaymentModal } from './components/PaymentModal';

function PricingPage() {
  const [showPayment, setShowPayment] = useState(false);

  return (
    <>
      <button onClick={() => setShowPayment(true)}>
        Купить подписку
      </button>
      
      <PaymentModal 
        isOpen={showPayment}
        onClose={() => setShowPayment(false)}
        planName="Про"
        amount="2990"
        period="/мес"
        features={['Все шаблоны', 'API доступ', 'Приоритетная поддержка']}
        templateName="AI Content Studio"
        templatePrice="7990"
      />
    </>
  );
}
```
