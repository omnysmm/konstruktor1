## Как использовать

### 1. Запуск приложения
```bash
npm run dev
```

### 2. Вход в систему
- Нажмите "🔐 Войти"
- Введите: `admin` / `admin`
- Нажмите "Войти"
- Автоматически запускается тестовый период (48 часов)

### 3. Использование сервисов

#### Генерация постов
1. Нажмите на карточку "Генерация постов"
2. Введите тему
3. Добавьте ключевые слова
4. Настройте тональность и длину
5. Нажмите "Сгенерировать пост"

#### Озвучка
1. Нажмите на карточку "Озвучка"
2. Введите текст
3. Выберите голос
4. Настройте скорость
5. Нажмите "Озвучить текст"

#### Генерация видео
1. Нажмите на карточку "Генерация видео"
2. Опишите видео
3. Настройте длительность, разрешение, стиль
4. Нажмите "Создать видео"

#### Генерация музыки
1. Нажмите на карточку "Генерация музыки"
2. Опишите музыку
3. Выберите жанр и настроение
4. Настройте длительность
5. Нажмите "Создать музыку"

#### Статьи с изображениями
1. Нажмите на карточку "Статьи с изображениями"
2. Введите заголовок и тему
3. Выберите количество и стиль изображений
4. Нажмите "Создать статью"

#### Видеомонтаж
1. Нажмите на карточку "Видеомонтаж"
2. Загрузите видеоклипы
3. Выберите режим (ручной/авто)
4. Отредактируйте порядок клипов
5. Нажмите "Смонтировать видео"

#### Автопубликация
1. Нажмите на карточку "Автопубликация"
2. Введите контент
3. Выберите соцсети
4. Выберите режим (сейчас/по расписанию)
5. Нажмите "Опубликовать"

#### Аналитика
1. Нажмите на карточку "Аналитика"
2. Выберите период (неделя/месяц)
3. Просмотрите общую статистику
4. Изучите статистику по соцсетям

#### Тарифы
1. Нажмите на карточку "Тарифы"
2. Выберите период оплаты (месяц/год)
3. Сравните тарифы
4. Выберите подходящий план
