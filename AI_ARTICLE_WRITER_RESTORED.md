## Как использовать

### 1. Запуск приложения
```bash
npm run dev
```

### 2. Вход в систему
- Нажмите "🔐 Войти"
- Введите: `admin` / `admin`
- Нажмите "Войти"
- Автоматически запускается тестовый период (48 часов)

### 3. Использование AI Article Writer
1. Нажмите на карточку "AI Article Writer"
2. Перейдите на вкладку "✨ Создать статью"
3. Введите тему статьи
4. Добавьте ключевые слова (опционально)
5. Настройте параметры:
   - Длина: короткая/средняя/длинная
   - Тональность: профессиональная/дружеская/академическая/креативная
   - Стиль: блог-пост/новостная статья/руководство/обзор
   - SEO-оптимизация: вкл/выкл
   - Изображения: вкл/выкл
6. Нажмите "✨ Сгенерировать статью"
7. Дождитесь генерации (3 секунды)
8. Статья появится во вкладке "📚 История"

### 4. Управление статьями
- **Просмотр:** нажмите "Просмотр" для открытия модального окна
- **Публикация:** нажмите "Опубликовать" для мгновенной публикации
- **Планирование:** нажмите "Запланировать" и укажите дату
- **Экспорт:** нажмите "Экспорт ▾" и выберите формат
- **Удаление:** нажмите "Удалить" для удаления статьи

### 5. Просмотр аналитики
1. Перейдите на вкладку "📊 Аналитика"
2. Просмотрите общую статистику
3. Изучите статистику по социальным сетям
4. Проверьте количество публикаций, лайков и просмотров
